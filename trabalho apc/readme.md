# Explorador PDAD 2024 - Saúde e Serviços (Recorte C)

Este sistema com interface gráfica permite explorar os microdados do PDAD 2024 do Distrito Federal, com foco no Recorte C: Saúde e Acesso a Serviços. O programa permite que o usuário filtre as informações por Região Administrativa (RA), visualize estatísticas como média de idade e mediana de renda, e analise um gráfico dinâmico mostrando a correlação entre faixa de renda e acesso a planos de saúde.

## Como executar
No terminal da sua máquina, navegue até a pasta do projeto e execute:
`python sistema.py`

## Dependências
As bibliotecas necessárias para o sistema rodar estão listadas abaixo. Você pode instalá-las usando o pip:
`pip install pandas matplotlib`

## Arquivos de dados necessários
O programa busca os dados na pasta `dados/`. Você precisa colocar o arquivo lá antes de iniciar:
- `PDAD_2024-Moradores.csv`
