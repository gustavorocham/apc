# apc
EXERCICIOS SEMANAIS DE APC
SEMANA 1 e 2 
Dominar a lógica de algoritmos através do LMC foi uma experiência essencial para entender como a computação funciona na prática. Nesse processo, o suporte do Octopus Studio ajudou muito, sendo um aliado importante para traduzir esses conceitos de baixo nível e consolidar meu aprendizado de forma bem mais clara e direta.

SEMANA 3
Aprendi a usar o plano de coordenadas $X$ e $Y$ para posicionar elementos e desenhar formas geométricas.Utilizei variáveis e números aleatórios para criar projetos dinâmicos e menos estáticos.Comecei a trabalhar com Sprites, manipulando imagens através de propriedades como escala e rotação.

SEMANA 4
Entendi o funcionamento do Draw Loop, que atualiza a tela constantemente para criar a ilusão de movimento.
Apliquei o "padrão de contador" e estruturas condicionais (if/else) para dar inteligência ao código.
Desenvolvi controles para que o programa reaja instantaneamente ao pressionar teclas ou clicar com o mouse.

SEMANA 5
Simulei comportamentos realistas usando conceitos de velocidade e sistemas de colisão entre objetos.
Aprendi a organizar meu código em blocos limpos e reutilizáveis através do uso de Funções.
Integrei design, lógica e física para construir o meu projeto final: um jogo completo criado do zero.
