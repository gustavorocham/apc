Fiz exercícios preparatórios para a prova utilizando o Pandas no Jupyter Notebook para analisar dados de moradores e domicílios da PDAD. No nível 1, praticamos a leitura de arquivos, seleção de colunas específicas e contagem de dados por habitação. No nível 2, enfrentamos a complexidade de erros no código ao calcular médias aritméticas de idade e tratar valores inconsistentes com testes booleanos. Por fim, mesmo após falhas na ferramenta que nos levaram a acompanhar as etapas de filtragem e contagem de forma demonstrativa com o professor, fechamos a semana discutindo técnicas de ordenação de dados, com destaque para a eficiência do algoritmo Quick sort.
